Startup & Initialization Sequence
1

UGameInstance initializes subsystems

UEventBusSubsystem comes up first (declared as dependency by SimulationSubsystem). No state yet — just delegate containers ready for subscription.

2

USimulationSubsystem initializes

Registers its SimTick timer at 20Hz. RNG not seeded yet — timer fires but tick is a no-op until seed is set by GameMode.

3

ASubLevelGameMode::InitGame fires

Generates or loads seed. Calls Sim->InitializeRNG(Seed). Stores seed in ASubLevelGameState. All subsequent RNG draws are deterministic from this point.

4

AParkingFloor actors register themselves

Each floor calls Sim->RegisterFloor(Index, this) in BeginPlay. B1 pre-built — grid populated with initial layout. B2–B5 empty, flagged locked.

5

Incident scheduler seeds initial event queue

One FPendingEvent per incident type per unlocked floor is pushed to the min-heap. Each draws its first interval from the Poisson sampler.

6

ASubLevelGameMode::StartPlay — simulation live

SimTick is now fully operational. Vehicles begin spawning via UCitySubsystem demand curve. HUD subscribes to EventBus delegates. Player is in control.

Inter-System Communication Map
Rule

No system holds a reference to another system. All communication is via UEventBusSubsystem delegates. If you find yourself doing GetSubsystem<UCitySubsystem>() inside SimulationSubsystem.cpp, stop — broadcast an event instead.

Known UE5 Pitfalls to Watch
⚠ Flow Field Thread Safety

Flow field recomputation runs on a Task Graph worker. Gate the vehicle movement phase of SimTick behind FGraphEventRef task completion. Never let a vehicle sample a partially-written flow field.

⚠ UPROPERTY on TMap

TMap<uint32, FVehicleData> in SimulationSubsystem is not marked UPROPERTY — intentional, since the keys are uint32 which UE5's reflection doesn't handle cleanly. Do not add UPROPERTY to these maps. Serialize them manually in the save system.

⚠ UWorldSubsystem Lifetime

SimulationSubsystem and CitySubsystem are UWorldSubsystem — they live and die with the World. EventBusSubsystem is UGameInstanceSubsystem — it persists across level loads. Don't subscribe to EventBus from a WorldSubsystem's constructor; subscribe in Initialize().
